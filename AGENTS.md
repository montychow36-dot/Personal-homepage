# System Rules

- **Design Concept**: This website acts as a physical handbook. Users are "looking at a book". 
- **Layout Constraints**: Keep focused on one page. Do not use slides or long scrolling galleries. The pages should feel like text pages of a book.
- **No Photos**: Keep the layout pure text unless explicitly requested otherwise. Avoid standard photo grids or modern gallery placeholders.
- **Menu Structure**: The hamburger menu is positioned on the left. It contains 4 main subjects (Leather 1, Leather 2, Others, Articles). Clicking these main subjects expands them to reveal nested, hidden choices (e.g. Cardholder, Coin Box, Leather Bag).
